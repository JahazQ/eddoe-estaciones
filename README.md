# EDDOE — Flujo de estaciones

Prototipo web del recorrido de la **Evaluación del Desempeño Docente Objetiva Estructurada (EDDOE)** de la Facultad de Medicina, UNAM.

Siete estaciones (0–6) que se habilitan de forma secuencial; cada una cambia de color al completarse:

- **Pendiente** — contorno gris
- **En curso** — azul institucional (#002B7A) con halo
- **Completada** — oro (#D59F0F)

## Publicar en GitHub Pages

1. Crea un repositorio **público** en GitHub.
2. Sube `index.html` y `.nojekyll` a la raíz.
3. Ve a **Settings → Pages** y elige **Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

`index.html` es autocontenido: incluye estilos, escudos e imágenes, y funciona sin conexión.
